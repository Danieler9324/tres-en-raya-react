# Tres en Raya (Tic-Tac-Toe) - React

Una versión interactiva del clásico juego de **Tres en Raya (Gato)** desarrollada en React. Este proyecto fue construido siguiendo las mejores prácticas de componentes, estado inmutable y renderizado dinámico.

---

## Características Principales

* **Juego Completo:** Detecta automáticamente victorias, empates y turnos entre 'X' y 'O'.
* **Historial de Movimientos:** Muestra una lista dinámica con cada jugada realizada.
* **Coordenadas de Jugada:** Indica la ubicación exacta de cada movimiento en formato `fila: (X), col (Y)`.
* **Viaje en el Tiempo:** Permite volver a cualquier estado o movimiento anterior del juego.
* **Ordenamiento Personalizado:** Botón de alternancia para ordenar los movimientos de forma ascendente o descendente.
* **Resaltado de Victoria:** Resalta de forma visual y animada la línea de casillas que causó la victoria.
* **Diseño Moderno y Responsivo:** Interfaz centrada, sombras suaves y colores contrastantes para una gran experiencia de usuario.
